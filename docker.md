# Guide d'utilisation du docker

1. Avoir installé Docker sur votre ordinateur (ne marche pas sur les ordinateurs de l'école)
2. Utiliser le Makefile pour vous faciliter la vie
```
make build  # A lancer une seule fois pour créer le docker (prends du temps)
make up     # Lance le docker et la connexion UI
make enter  #
make stop   #
```
